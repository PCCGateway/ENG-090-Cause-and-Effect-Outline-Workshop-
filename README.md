# The Glass Castle Cause & Effect Essay Prewriting Workshop

A single-page, student-facing prewriting activity for a remedial/high-school English course.

## Features
- Notes-to-essay scaffolding
- Cause/effect planning
- Sentence-starter choices with fill-in responses
- Three-quote and citation planning
- Two outside-source sections
- Vocabulary planning
- Thesis, introduction, body, transition, conclusion, abstract, and Works Cited planning
- Rubric readiness check
- Browser autosave using localStorage
- Two downloads: complete responses and clean working outline
- Print/Save as PDF option

## GitHub Pages
Upload `index.html` to a repository and enable GitHub Pages from the repository settings.

Student work stays in the browser's local storage unless the student downloads or prints it.
